## Evaluation criteria for graded programming exercise in TDT4225

This is related to the learning outcome of the course TDT4225

**Skills:** 
- Evaluate existing systems and solutions for distributed storage and management of data 
- How to combine tools to build the properties you need 
- Participate in the development of new systems for distributed storing and management of data

**Detailed criteria:**
- The import of data into the database should work correctly
- How to handle missing values and "buggy" data are of particular interest.
- The implemented functionality/queries should work correctly as desribed by problem text
- The implemented functionality/queries should be clear and easy to understand
- The efficiency of the code is not considered as an evaluation criteria in this exercise
- The connection to programming language should be clear and easy to understand
- The code should be implemented by the group members or by the use of AI tools (CoPilot, ChatGPT and similar).
- Describe in your answer where and how AI tools have been used..
- Clear and understandable report as described by the problem text
